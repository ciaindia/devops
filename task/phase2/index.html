Phase 2 — Terraform + GCP + Ubuntu

Objective: Deploy the same Docker-based application from Phase 1 to Google Cloud Platform using Terraform and an Ubuntu-based Compute Engine virtual machine.

1. Phase 2 Overview

Phase 2 extends the local DevOps project into the cloud. Infrastructure will be created using Terraform instead of manually creating resources through the GCP Console.

The application will run on an Ubuntu Server VM inside Google Cloud Platform.

4. Terraform Infrastructure

Terraform shall provision and manage the required GCP infrastructure.

  • GCP Compute Engine VM
  • Ubuntu LTS operating system
  • VPC network
  • Subnet
  • Firewall rules
  • External IP address
  • Required IAM/service account permissions

5. Compute Engine

6. Docker Deployment

The Docker configuration created in Phase 1 should be reused wherever practical.

The Ubuntu VM shall run the application using Docker Compose. 

docker compose up -d

7. Firewall Requirements

Terraform shall configure the required GCP firewall rules.

Port Purpose
22 SSH administration
80 HTTP website
443 HTTPS - future phase

Monitoring ports such as Grafana or Prometheus should not be publicly exposed unless specifically required. Access should preferably be restricted.

9. Application Deployment

Once the Ubuntu VM is available, the deployment process shall:

  1. Install or verify Docker.
  2. Install or verify Docker Compose.
  3. Obtain the application source/configuration.
  4. Build or pull the Docker image.
  5. Stop the previous application version.
  6. Start the new container.
  7. Perform a health check.

12. Terraform Learning Objectives

  • Understand Infrastructure as Code.
  • Install and configure the GCP Terraform provider.
  • Create a Compute Engine VM.
  • Create VPC and subnet resources.
  • Create firewall rules.
  • Use Terraform variables.
  • Use Terraform outputs.
  • Understand Terraform state.
  • Run terraform init.
  • Run terraform plan.
  • Run terraform apply.
  • Run terraform destroy.

14. Success Criteria

  1. Terraform successfully provisions GCP infrastructure.
  2. Compute Engine VM runs Ubuntu LTS.
  3. Docker is available on the VM.
  4. Nginx container runs successfully.
  5. The HTML website is accessible through the VM's external IP.
  6. Firewall rules allow required traffic.
  7. Infrastructure can be recreated using Terraform.
  8. Infrastructure can be removed using terraform destroy.
  9. GitHub Actions can automate the deployment process.
